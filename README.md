# AlbTasks 

Um gerenciador de demandas minimalista focado em reduzir a carga mental durante o fluxo de trabalho. Em vez de listas gigantes, o AlbTasks separa suas atividades em pipelines padronizados e exibe apenas a tarefa atual, ajudando você a manter o foco.

## Tecnologias
- C# .NET 8.0
- Windows Presentation Foundation (WPF)
- Arquitetura MVVM (Model-View-ViewModel)
- Armazenamento local leve em formato JSON (Sem necessidade de banco de dados)

## Funcionalidades
- **Pipelines Customizáveis:** Crie e edite seus fluxos de trabalho facilmente em um arquivo `.json`.
- **Foco Absoluto:** Interface minimalista que exibe apenas o passo atual da demanda.
- **Multitarefas:** Alterne entre diferentes demandas em andamento com poucos cliques.
- **Always on Top:** O aplicativo atua como um widget flutuante, sempre visível sobre outras janelas.
